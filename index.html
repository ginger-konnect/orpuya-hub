1. Hosting & Custom Domain Deployment Guide

To make orpuya_master_campaign_hub.html accessible online 24/7 with zero hosting costs, follow these step-by-step instructions.

Option A: Hosting via GitHub Pages & Linking a .co.ke Domain (Recommended)

  1. Prepare the App File: Take the single-file HTML app code and save it on your computer as index.html (in lowercase).
  2. Set Up GitHub Repository: Log into GitHub and click New repository. Name the repository orpuya-hub (or narok-north-hub). Select Public visibility and click Create repository.
  3. Upload index.html: On the repository page, click Add file > Upload files. Drag and drop your index.html file. Click Commit changes.
  4. Enable GitHub Pages: Navigate to Settings > Pages. Under Build and deployment > Branch, select main (or master) and keep / (root) selected. Click Save. Within 1–2 minutes, your live site will be accessible at: 
    https://<your-github-username>.github.io/orpuya-hub/
  5. Link a Custom Domain (orpuya.co.ke):
    • Purchase orpuya.co.ke from an accredited KeNIC registrar (e.g., HostPinnacle, SasaHost, or Kenya Web Experts).
    • In your registrar's DNS Management panel, set up the following records:
    A Records pointing to GitHub Pages IPs:
    185.199.108.153
    185.199.109.153
    185.199.110.153
    185.199.111.153

    CNAME Record: www pointing to <your-github-username>.github.io

    In your GitHub repository Settings > Pages, type orpuya.co.ke into the Custom domain box, click Save, and check Enforce HTTPS.

3. Field Agent Tablet Training & Deployment Manual

A. Morning Setup & Device Configuration

  1. Cache Application for Offline Mode: Open Chrome on the field tablet, load orpuya.co.ke, tap Options (3 dots) > Add to Home screen. This creates an offline-ready PWA icon.
  2. Sync Verification: Ensure mobile data or Wi-Fi is toggled ON at 7:30 AM to push queued offline submissions from the previous day into the central campaign analytics server.

C. Protocol for Handling Data-Hesitant Voters

  • Security Reassurance: Emphasize that national ID numbers are encrypted and strictly used for bursary verification and group insurance enrollment.
  • Paper Backup Workflow: If a voter prefers not to input details directly into the tablet, fill out a physical paper registration slip, tear off the tracking receipt for the voter, and manually enter the data at headquarters at the end of the shift.
